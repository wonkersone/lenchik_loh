# ДР-Аркада Ленчика

Статический сайт для GitHub Pages с восемью пиксельными мини-играми про Ленчика.

## Игры

- Ударь Ленчика
- Где Рюкзак?
- Ленчик На Стройке
- Формула Леня
- Греби, Ленчик
- Counter-Lenchik
- Три В Ряд
- Побег С Парты

## Локальный запуск

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Открыть: `http://127.0.0.1:4173`

## Хостинг

Проект готов для GitHub Pages из корня ветки.
