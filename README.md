# Pixel Birthday Arcade

Интерактивный веб-сайт с набором мини-игр в пиксельном стиле, сделанный как персональный подарок ко дню рождения друга. Проект собран как цельная browser arcade: с главным меню, адаптивным игровым экраном, собственными спрайтами, прогрессом в `localStorage` и публикацией через GitHub Pages.

## Что внутри

- 6 мини-игр с разными механиками: поиск предмета, whack-a-mole, stack-builder, аркадная гонка, ритм-игра и match-3.
- Единый пиксельный визуальный стиль: персонажи, фоны, игровые объекты, UI-плашки и анимации.
- Адаптация под desktop и mobile: отдельные вертикальные игровые поля для телефона, touch-управление и компактный HUD.
- Игровая экономика: очки сбалансированы так, чтобы разные мини-игры давали сопоставимый результат за хорошую попытку.
- Статический деплой: сайт не требует backend и работает как GitHub Pages-проект.

## Технологии

- HTML5 Canvas для игровой графики и анимаций.
- Vanilla JavaScript для игровых циклов, коллизий, таймеров, состояний и прогресса.
- CSS для адаптивной оболочки, пиксельного интерфейса и мобильной раскладки.
- GitHub Actions и GitHub Pages для публикации.

## Игры

- `Find the Backpack` — игра на внимательность: найти единственный нужный объект среди множества предметов.
- `Whack Game` — реакционная игра с лунками, появляющимися персонажами и штрафом за неправильный тап.
- `Builder` — stacking-игра: нужно точно ставить этажи друг на друга.
- `Race` — аркадная гонка с полосами, препятствиями, монетами и ускорением.
- `Rowing Rhythm` — ритм-игра с таймингом на левую и правую сторону.
- `Match-3` — поле 5 на 5 с проверкой ходов, автоочисткой совпадений и перемешиванием.

## Запуск

Проект можно открыть как обычный статический сайт. Для локальной проверки удобнее поднять простой сервер из корня проекта:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

После этого открыть:

```text
http://127.0.0.1:4173
```

## Структура

```text
assets/
  backgrounds/    # игровые фоны для desktop и mobile
  sprites/        # персонажи, предметы, машинка, лодка и игровые слои
game.js           # логика игр, загрузка ассетов, игровой цикл
index.html        # оболочка сайта
styles.css        # визуальная система и адаптив
```

## Результат

Проект демонстрирует полный цикл создания небольшого интерактивного продукта: идея, дизайн-направление, генерация и ручная доработка ассетов, реализация нескольких игровых механик, мобильная адаптация, оптимизация ассетов и деплой.
