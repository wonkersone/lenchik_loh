# ДР-Аркада Ленчика

Статический сайт для GitHub Pages с пиксельной аркадой ко дню рождения Ленчика.

## Игры

- Где рюкзак?
- Не бей Еву
- Стройка Лени
- Формула Леня
- Гребной ритм
- Матч эмоций
- Башня из учебников

## Локальный запуск

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Открыть: `http://127.0.0.1:4173`

Отдельную игру можно открыть через hash, например `/#race` или `/#whack`.

## Хостинг

Проект готов для GitHub Pages из корня ветки.
